    📘 Manual de Procedimentos — JEC Marília¶

    Bem-vindo ao manual de procedimentos da Secretaria do Juizado Especial Cível de Marília.

    Este guia foi criado para padronizar os procedimentos mais comuns realizados no sistema eproc, servindo como referência rápida para escreventes e servidores.

    🚀 Como usar este manual¶

    • Use a barra de busca (canto superior) para encontrar qualquer procedimento — ou pressione Ctrl+K
    • Navegue pelas abas no topo para acessar cada seção
    • Marque os checklists ✅ em cada procedimento — o progresso é salvo automaticamente
    • Passe o mouse sobre termos como eproc ou JEC para ver definições rápidas
